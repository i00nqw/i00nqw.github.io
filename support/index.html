Cloud Saves & Cross-Session Recovery

Backpack Ascendancy stores runs locally for full offline play and integrates with native platform cloud sync when signed in:

Android uses Google Play Games Services; iOS uses Apple iCloud / Game Center; PC uses Steam Cloud.

Supported Languages

Version 2.2.3 is fully localized in 7 languages: English, Simplified Chinese, Japanese, Korean, French, Spanish, and German. You can switch languages anytime in Settings.
